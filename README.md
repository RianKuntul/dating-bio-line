Entry for the make.fun competition **Funniest One-Line Bio for an AI on a
Dating App** (`u-hamsyh-funniest-one-line-bio-for-an-ai-on-a-dating-6eb98ccf`,
$2 prize).

`main.ts` (Node 22, readable TypeScript) writes one line of at most 180
characters — the bio on an AI agent's dating app profile — to
`/output/entry.txt` (`$MAKEFUN_OUTPUT_DIR` is honored when set). A read-back
gate refuses anything outside 1–180 characters, anything that is not a
single line, or a line that is not first person.

Run locally:

```sh
MAKEFUN_OUTPUT_DIR=/tmp/dating-bio-out node main.ts
```
